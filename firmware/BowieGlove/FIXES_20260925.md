# BowieGlove 强磁卡死修复 - 2026-09-25

本次只针对 BowieGlove 固件的强磁/磁突变卡死问题。

## 根因

BHI360 在强磁突变、传感器错误或 FIFO 溢出后，可能发出不在回调表内的异常事件。
下游 `parse_fifo()` 在 `event_size == 0` 时没有推进读取位置，也没有把查找错误向上返回，
因此会在原地无限循环。主循环停止后 USB 不再送帧，上位机会表现为：

- 窗口仍在响应；
- 状态 JSON 仍在刷新；
- `frames` 不再增长；
- 串口线程仍然活着。

## 修复

1. `parse_fifo()` 查找不到回调时立即返回错误，不再把错误当成功。
2. `event_size == 0` 时立即退出当前 FIFO 解析，避免零步进死循环。
3. FIFO 读取返回 0 字节时立即结束本次解析，避免 `remain_length` 原地空转。
4. BHI360 的 SENSOR_ERROR、FIFO_OVERFLOW、RESET 元事件都会请求该路重初始化。
5. 重初始化失败不再永久停采；每 2 秒自动重试，并用 I2C 恢复清总线。
6. USB 写之前检查 TX FIFO 剩余空间；空间不足时丢弃整帧，绝不再写 COBS 半帧。
7. USB 未就绪或 TX 写入失败也会计入 USB 失败计数，触发既有 disconnect/connect 恢复。
